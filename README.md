# DSA_HW01: Sparse Matrix

## Overview

This project is part of the Data Structures and Algorithms (DSA) course. The primary focus of this assignment is to implement and manipulate sparse matrices efficiently. Sparse matrices are matrices in which most of the elements are zero. Efficient storage and manipulation of such matrices can save both memory and computational resources.

## Objectives

- Understand the concept of sparse matrices.
- Implement data structures to store sparse matrices efficiently.
- Perform operations such as addition, multiplication, and transposition on sparse matrices.
- Analyze the time and space complexity of the implemented algorithms.

## Project Structure

- `src/`: Contains the source code for the project.
- `tests/`: Contains the test cases to validate the implementation.
- `docs/`: Contains documentation related to the project.
- `README.md`: This file, providing an overview of the project.

## Getting Started

### Prerequisites

- A working installation of Python 3.x.
- Basic understanding of data structures and algorithms.

### Installation

1. Clone the repository:
    ```sh
    git clone https://github.com/kelvintawe12/DSA_HW01-Sparse-Matrix.git
    ```
2. Navigate to the project directory:
    ```sh
    cd DSA_HW01-Sparse-Matrix
    ```

## Usage

### Running the Code

To run the main program, execute:
```sh
python src/main.py
```

### Running Tests

To run the test cases, execute:
```sh
python -m unittest discover tests
```
